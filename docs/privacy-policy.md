# NARADA Privacy Policy

**Effective date:** 30 September 2026

NARADA is an Android application for searching and working with curated Indonesian banking regulations. NARADA is not an official OJK application.

## Data collected by the developer

NARADA does **not** require an account and does not include advertising, analytics, behavioral tracking, or a developer-operated backend for the current release. The developer does not collect or sell personal data through the app.

## Data stored on the device

The following information can be stored locally inside the application sandbox:

- bookmarks and recent searches;
- personal notes and licensing-checklist progress;
- downloaded OJK PDF files; and
- text indexes generated from downloaded PDFs for offline search.

This local workspace data is not synchronized to a NARADA server. Android cloud backup and device-to-device transfer are explicitly excluded for the application data.

## Network access

NARADA uses internet access to open official OJK web pages in the device browser and to download official regulation attachments directly from HTTPS hosts under `ojk.go.id`. Normal network metadata such as IP address and HTTP request information may therefore be processed by OJK and the user's network provider under their own policies.

## Clipboard, sharing, and external applications

Copy and share actions happen only when initiated by the user. Content copied to the Android clipboard or shared to another application is then subject to Android and the selected application's handling. Official source links are opened outside NARADA using the device's HTTPS-capable browser or application.

## Deletion

Users can delete downloaded PDFs from the Info screen. The **Hapus seluruh data lokal** action removes NARADA bookmarks, notes, checklists, recent searches, and offline documents from the application workspace. Uninstalling the application also removes its sandboxed application data, subject to Android platform behavior.

## Security

NARADA blocks cleartext network traffic, restricts native document downloads to official HTTPS OJK hosts, validates redirect destinations, and keeps its PDF content provider non-exported.

## Changes to this policy

If NARADA later adds accounts, remote synchronization, analytics, crash reporting, or another feature that changes data handling, this policy and the Google Play Data Safety declaration must be updated before that feature is released.

## Contact

Privacy or security questions can be raised through the NARADA GitHub repository's issue or security-reporting channels.
