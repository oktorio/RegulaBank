# Content Rating / Play Console Worksheet — NARADA

This is a preparation worksheet, not a substitute for the questionnaire presented by Google Play / IARC.

## App content profile

NARADA is a professional productivity/reference application containing banking-regulation text, editorial summaries, official-source links, local notes, and licensing checklists.

Expected content characteristics for the current build:

- Violence / graphic content: none intentionally provided by the application.
- Sexual content / nudity: none.
- Profanity / crude humor: none.
- Controlled substances: none as an application theme.
- Gambling: none as an application theme.
- User-to-user communication: none.
- Public user-generated content: none.
- Purchases / loot boxes / gambling mechanics: none.
- Advertising: none.
- Location sharing: none.
- Social networking: none.
- Web browsing: external official-source HTTPS links can be opened in the user's browser; NARADA itself does not provide a general-purpose browser.
- User notes: private, local-only workspace content; not published or shared with other NARADA users.

## Submission action

Answer the final IARC/Play Console questionnaire according to the production binary and the wording shown at submission time. If future releases add community content, embedded browsing, advertisements, payments, or other materially different features, repeat the rating review.
